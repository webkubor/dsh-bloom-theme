Hi all — sharing **[dsh-bloom-theme](https://github.com/webkubor/dsh-bloom-theme)**, a Morandi palette theme for the DSH Web UI.

It's more than a recolor:

- **Two-track palette** — readable-text accent (darkened) and ambient-gradient accent (desaturated Morandi) are kept separate. Carrying only the first would turn `petal` from lotus pink into fluorescent magenta, so both tracks were ported from the [Bloom for Typora](https://github.com/webkubor/typora-Bloom-theme) original.
- **Texture layer** — ambient gradients, cool hairlines, layered shadows, and Markdown detailing, not just remapping DSH color tokens.
- **Accessibility** — all 8 foreground/background pairs were computed (OKLCH → sRGB → WCAG) and land at ≥ 4.5:1; the light accents for `petal` and `ripple` were darkened specifically to reach AA.

  <details>
  <summary>Measured contrast (all 8 pairs, computed by <a href="https://github.com/webkubor/contrast-guard">contrast-guard</a>)</summary>

  | Variant | Mode | Accent | Background | Ratio | WCAG |
  |---|---|---|---|---:|---|
  | `mist` | light | `#34698c` | `#ecf3f8` | **5.28:1** | AA |
  | `mist` | dark | `#55aee8` | `#202a32` | **5.96:1** | AA |
  | `cinnabar` | light | `#c53637` | `#f8f4f3` | **4.87:1** | AA |
  | `cinnabar` | dark | `#e6857e` | `#322524` | **5.63:1** | AA |
  | `petal` | light | `#d0268c` | `#fef6f9` | **4.55:1** | AA |
  | `petal` | dark | `#ff78be` | `#31252a` | **6.07:1** | AA |
  | `ripple` | light | `#007a7b` | `#ebf4f4` | **4.61:1** | AA |
  | `ripple` | dark | `#2cc5c5` | `#0a1919` | **8.51:1** | **AAA** |

  Lowest 4.55:1, highest 8.51:1 — one pair reaches AAA. Reproduce with `npm run check:contrast`
  in the repo; it parses the OKLCH values straight out of `lib/client.js`, so the numbers can't
  drift away from the shipped palette.

  `petal` and `ripple` light accents used to sit at 3.55:1 and 3.02:1 — both were darkened
  until they cleared the 4.5 line.
  </details>
- **Doesn't cover native controls** — the variant switcher mounts into the DSH top-bar utilities area next to `Session log` instead of floating above it.

### Install

```bash
dsh plugin add @kubor/dsh-bloom-theme
```

Or install from source:

```bash
git clone https://github.com/webkubor/dsh-bloom-theme
cd dsh-bloom-theme
npm install && npm run deploy    # rsync into the active profile
```

### Compatibility & non-goals

- Tested on `@deepseek-ai/dsh` 0.1.0-rc.6 (macOS / Node 24)
- Works alongside the awesome-dsh-plugin listing ([#1672](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/pull/1672))
- **Does not** add an image-upload button to the composer — that's a DSH-side affordance; if your team packages don't cover multimodal models (most don't — BigModel returns `取值范围 ['text']` on the anthropic-compat endpoint), adding the button is moot anyway.
