Hi all — sharing **[dsh-bloom-theme](https://github.com/webkubor/dsh-bloom-theme)**, a Morandi palette theme for the DSH Web UI.

It's more than a recolor:

- **Two-track palette** — the readable-text accent (darkened) and the ambient-gradient accent (desaturated Morandi) are kept separate. Carrying only the first turns `petal` from lotus pink into fluorescent magenta, so both tracks were ported from the [Bloom for Typora](https://github.com/webkubor/typora-Bloom-theme) original.
- **Glass, not just color** — semi-transparent panels with `backdrop-filter` blur and a lit glass edge (top inset highlight + hairline stroke + soft outer glow), at two opacity steps for light and dark.
- **Restrained motion** — menu entry, selection bar slide-in, hover/press feedback, all on shared duration/easing tokens, and it honours `prefers-reduced-motion`.
- **Accessibility, measured not claimed** — every text token is computed across all 16 palette-by-mode combinations. See the table below; the numbers come out of `contrast-guard --json`, which parses the shipped OKLCH values, so they cannot drift away from what users actually install.
- **Doesn't cover native controls** — the switcher mounts into the DSH top-bar utilities area next to `Session log` rather than floating over it.

### Install

```bash
dsh plugin add @kubor/dsh-bloom-theme
```

Or from source:

```bash
git clone https://github.com/webkubor/dsh-bloom-theme
cd dsh-bloom-theme
npm install && npm run deploy    # rsync into the active profile
```

### Compatibility & non-goals

- Tested on `@deepseek-ai/dsh` 0.1.0-rc.6 (macOS / Node 24)
- Listed in awesome-dsh-plugin ([#1672](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/pull/1672))
- **Not a feature plugin.** It used to ship a `/bloom stats` code-stats card; that was removed in 0.8.0 — the browser side could not reach local git data, so the card had been rendering hard-coded sample numbers the whole time. A theme should not need a fake data path to justify itself.
