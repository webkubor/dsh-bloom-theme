# Bloom for DSH 0.27.0 版本说明（候选）

> 候选版本号来自当前 Release Please 提案；本文件是发布前审核稿，并不代表版本已发布。

## 一眼看到的新变化

### 三种玻璃质感

新增「毛玻璃」「磨砂玻璃」「液态玻璃」三种质感。侧栏、顶部栏、输入卡片和底部控制区跟随统一选择；磨砂带有细颗粒，液态玻璃在边缘呈现折射光。深色和浅色共用同一个质感偏好。

### 深浅色，各有自己的背景

「质感」与「背景」现在分开调整，互不影响。深色和浅色各自记住选择，切换外观时无需重新设置：

- **深色**：对角漫染、漫天星辰、角落微光、不显示。
- **浅色**：斜光流转、水彩晕染、清透留白、不显示。浅色背景跟随当前皮肤主色，搭配协调色自然过渡到白色。

「漫天星辰」加入更丰富的萤火虫般星辉，流星保留原有的数量和轨迹。流星可选纯色或彩色；切换主题时，正在飞行的流星保留旧色，新一轮流星才采用新色。星辉与流星只在深色下显示。

### 跟随皮肤的玻璃发送按钮

发送按钮调整为半透明玻璃珠，颜色随皮肤变化；发送中的转圈状态也使用同一套玻璃样式。

### 更紧凑的菜单与分享入口

质感选择改为紧凑的三段式按钮。底栏收敛为「反馈」「点个星」「分享」：反馈打开附有基础诊断的待填写页面；点个星进入 GitHub 仓库；分享可以复制安装提示词，直接发给 Agent。

分享菜单还提供截图与约 5 秒录屏入口，按设计由用户选择屏幕、窗口或标签页，不录制声音，也不自动上传。**当前桌面实测尚未弹出选源窗口，不能将截图和录屏描述为桌面已验证可用。**

## 修复与改进

- 深色皮肤统一恢复多角主题色柔光，输入区与背景采用同一套屏幕坐标，修复可能出现的水平色阶断层。
- 改进宽表格的容器边界与横向滚动处理。
- 修复深浅外观初始化时序问题。
- 存储被系统或隐私模式拒绝时，在当前会话中保留材质和背景选择；兼容旧材质偏好。
- 保留高对比度、强制颜色、减少透明度和减少动效等系统设置的相应降级。
- 重写中英文 README，突出效果、安装方式和分享入口。
